# Hi, I'm Shakeel 👋

Full-stack developer — Vue, Node.js, Laravel, Next.js.

## 🛠️ What I'm building

**[SolveBar](https://solvebar.com)** — 85 free browser-based tools for developers and crypto users.
Everything runs client-side: no uploads, no signups, no data leaving your device.

- 📄 PDF tools — [merge](https://solvebar.com/tools/pdf-merger), split, compress, watermark
- 🖼️ Image tools — [convert](https://solvebar.com/tools/image-converter), resize, [EXIF viewer](https://solvebar.com/tools/exif-viewer)
- 👨‍💻 Dev tools — [JSON formatter](https://solvebar.com/tools/json-formatter), [regex tester](https://solvebar.com/tools/regex-tester), [JWT decoder](https://solvebar.com/tools/jwt-decoder)
- ⛓️ Crypto tools — [ABI decoder](https://solvebar.com/tools/abi-decoder), [wallet age checker](https://solvebar.com/tools/wallet-age-checker), [multi-wallet checker](https://solvebar.com/tools/multi-wallet-checker)
